# Car Price Prediction 🚗💰

A machine learning project that predicts the selling price of a car based on its features like name, year, company, fuel type, and more.

## 🔍 Problem Statement
Predicting the accurate resale price of used cars helps both buyers and sellers make informed decisions. This project uses supervised learning to estimate car prices using historical data.

## 📊 Features Used
- Car Brand & Model
- Year of Manufacture
- Kilometers Driven
- Fuel Type (Petrol, Diesel, etc.)
- Transmission (Manual/Automatic)

## 🛠️ Technologies & Tools
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
- Jupyter Notebook
- Flask (for web deployment)

##  📈 Model Used
- Linear Regression
- Random Forest Regressor
- XGBoost Regressor
- Evaluation is done using metrics like R² Score, MAE, and RMSE.

## 📦 Output
-The model predicts the price of a car when user inputs features like brand, year, mileage, fuel type, etc.
